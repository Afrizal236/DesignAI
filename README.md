# DesignAI 🤖

DesignAI is an AI-powered platform that helps users generate creative product designs using Text-to-Image technology and Image Recommendation systems. Users can transform text prompts into unique design concepts or upload product images to receive AI-generated design inspirations.

🌐 Live Demo: https://designai.unesa.dev/

## Features

- Text-to-Image Generation
- Image Recommendation
- AI-Powered Product Design
- Responsive User Interface

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript

### Backend
- FastAPI
- Python

### Database
- PostgreSQL
- Redis

### AI Services
- Google Gemini API
- NanoBanana API
